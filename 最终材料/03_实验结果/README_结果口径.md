# 实验结果阅读说明

两个子目录保留原实验的全部配置、CSV、图表、失败诊断和求解日志。metadata.json中的绝对路径是历史运行记录；复现时使用02_项目源码内的配置。

| 实验 | 请求区间 | 三策略共同有效日期 | 覆盖率 |
| --- | --- | --- | --- |
| 默认5 kWh | 2010-01-04至2010-01-10 | 2010-01-05、2010-01-10 | 2/7 = 28.57% |
| 3 kWh参数情景 | 同上 | 2010-01-08、2010-01-09、2010-01-10 | 3/7 = 42.86% |

默认预测MAE为0.701245 kW、RMSE为0.991260 kW，样本为7日168小时。费用仅汇总两个共同有效日：无储能53.861140元、固定规则51.324298元、优化50.050614元，节省7.0747%。日期按回测可执行性事后筛选，所得是条件比较。五日优化计划放电超过真实负荷，空费用不能当作0元。

3 kWh情景同时将容量、最大电量、初始电量改为3.0、2.5、1.5 kWh，不属于单因素容量敏感性分析。两组共有有效日只有2010-01-10：优化费用分别为26.558437元和27.511068元。不能直接比较覆盖日不同的总费用。

优先查看summary.json了解有效日期、失败数量和评价样本；cost_comparison.csv查看每日费用及失败原因；diagnostics.json查看逐时违反量；metadata.json查看来源、哈希与版本。figures中的失败日调度图保留无效标记。

电价和电池为实验设定，费用只含购电运行费用，未计投资或老化，也未接入实际设备。

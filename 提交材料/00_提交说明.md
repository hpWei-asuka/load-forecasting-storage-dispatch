# 用电负荷预测与储能调度优化｜提交材料

本包包含用电负荷预测与储能调度项目的报告、代码和实验结果，可作为小组申请中的项目材料。

## 建议阅读顺序

1. **01_项目报告.pdf**：4页，说明问题、模型、实验和局限；同名Markdown为文字版。
2. **02_项目源码/README.md**：运行说明，附源码、配置、锁定依赖和测试。
3. **03_实验结果/**：5 kWh默认情景与3 kWh参数情景的完整输出。
4. **04_设计文档/**：产品范围和技术实现说明。
5. **05_图示与诊断/**：流程图源文件、预测诊断图及绘图数据。

只允许上传一个附件时，提交“提交材料.zip”；允许分开上传时，可另附项目报告PDF。

## 结果口径

预测评价覆盖7日168小时。默认三策略的共同有效日为2010-01-05与2010-01-10（2/7，28.57%），优化节省率7.0747%仅对应这两日和假设电价。它属于事后筛选有效日期的条件比较，不能代表全周收益。其余五日优化计划在真实负荷下不可执行，费用留空；运行会保存全部结果并返回退出码1。

## 复现

在02_项目源码目录准备Python 3.12和uv，然后执行：

```powershell
uv sync --locked
uv run load-storage doctor
uv run load-storage download-data
uv run load-storage run --config configs/example.toml
uv run pytest
```

参数对照改用configs/capacity3.toml。文档检查可分别运行tests/Test-ProductDesign.ps1和tests/Test-TechnicalPlan.ps1。

原始公开数据约133 MB，按README下载；现有实验结果可直接阅读。文件校验清单.sha256覆盖除清单自身之外的全部文件。
